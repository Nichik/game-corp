# Шпион

**Цель:** формальная цель пока пустая (уточняется).

**Победные Очки:** получает ПО за каждый украденный выполненный проект (см. [[Правила/Правила#Победные Очки (ПО)\|Правила#Победные Очки (ПО)]]) — выполненный проект, ушедший к Конкуренту по [[Карты/Шпионаж\|«Шпионажу»]].

## Личная колода (3 карты)

[[Карты/Шпионаж\|Ш]], [[Карты/Шпионаж\|Ш]], [[Карты/Шпионаж\|Ш]] — три [[Карты/Шпионаж\|«Шпионажа»]], рука добирается до 6 из общей колоды в начале раунда.

## Связи

- Его антипод — [[Должности/Аудитор\|Аудитор]]: ищет его в конце игры (верный указатель — +1 ПО Аудитору).
