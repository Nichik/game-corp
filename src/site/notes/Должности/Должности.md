# Должности

Иерархия Корпорации: 5 бейджей — 1 [[Должности/Директор\|Директор]], 1 [[Должности/Менеджер\|Менеджер]], 3 [[Должности/Работник\|Работник]]а; плюс вторая, публичная должность [[Должности/Аудитор\|Аудитор]] (без бейджа, назначается выборами по сыгранному [[Карты/Шпионаж\|Шпионаж]]у). Должности меняются в игре: понижение Менеджера за провал, голосования сжиганием влияния, открытое голосование о повышении Менеджера до Директора. Никаких увольнений — только движение по лестнице. См. [[Правила/Правила\|Правила]], [[Дизайн/Компоненты\|Компоненты]].

| Должность    | Бейджей | Ядро роли                                                                                                                              |
| ------------ | ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| [[Должности/Директор\|Директор]] | 1       | получает 2 проекта от Менеджера, назначает себе и Менеджеру, руководит своим, 3 ВЕТО за игру, решает при равенстве голосов             |
| [[Должности/Менеджер\|Менеджер]] | 1       | берёт 3 проекта, отдаёт Директору 2, один сбрасывает; руководит своим, понижается за провал, может инициировать повышение до Директора |
| [[Должности/Работник\|Работник]] | 3       | исполнители: идут по зову (или отказываются), самовольно присоединяются, «аутсорс»; кандидаты на выборах                               |
| [[Должности/Аудитор\|Аудитор]]  | —       | вторая должность: обязан участвовать в проекте, аудирует любой проект; цель — угадать Шпиона (±1 ПО)                                   |

Ключевые механики: понижение Менеджера за провал проекта, голосование по [[Карты/Жалоба\|«Жалобе»]], выборы Менеджера сжиганием влияния, повышение Менеджера открытым голосованием (≥3 «за»), выборы Аудитора по [[Карты/Шпионаж\|«Шпионажу»]], аудит, «Тимбилдинг» (возврат карт из сброса) — [[Правила/Правила#Голосование о понижении по «Жалобе»\|Правила#Голосование о понижении по «Жалобе»]], [[Правила/Правила#Повышение Менеджера (голосование)\|Правила#Повышение Менеджера (голосование)]], [[Правила/Правила#Выборы Аудитора\|Правила#Выборы Аудитора]], [[Правила/Правила#4. Подведение итогов раунда\|Правила#4. Подведение итогов раунда]] (там «Тимбилдинг»).
