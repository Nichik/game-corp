## 2026-11-01 — тест 1 (3 партии, редакция до 2.0)

**Заменено в правилах по итогам теста** (полные формулировки — [[Резерв/Резерв\|Резерв]]):

- Общая открытая цель «≥8 влияния для всех» → открытые цели должностей (Директор: капитал Корпорации ≥ 8; Менеджер: капитал Корпорации ≥ своего влияния; Работник: ≥8 влияния).
- Цель Аудитора «верно обвинить шпиона» (одно обвинение за игру) → «спасти 2 проекта» через «Антишпионаж»: на столе следить оказалось тяжело, шпион ни разу не угадан, механику не вводили.
- Личные колоды по 6 карт → по 3 (Шпион ШШШ, Аудитор ААА, Планктон 222, Кардинал ЖЖ2, Бухгалтер ЖШ0) с добором до 6 из общей колоды. Старые колоды по 6 карт: Карьерист 22А111, Кардинал ЖЖ2110, Шпион ШШШЖ21, Бухгалтер ЖШ1110, Планктон 2222Ш1, Аудитор ААА211.
- Общая колода из только «0» и «1» → все типы карт (предварительно по 9 копий каждого + 15 единиц, гипотеза).
- Одновременный набор участников → чередование вызовов (Менеджер, Директор, Менеджер…).
- Старт без влияния → стартовая карта «0» в зону влияния каждому (блеф на голосованиях).
- Карьерист удалён из игры: цель «Директор в конце» избыточна при должностной цели Директора.
- Третья ветка цели Шпиона (≥2 украденных проекта суммарно ≥4) отброшена при сокращении до двух веток.

**Принято прямо на тесте:** чередование вызовов; цель Менеджера «капитал Корпорации ≥ суммы личного влияния Менеджера».

**Флаги теста** (разбор — [[Резерв/Резерв\|Резерв]], [[Резерв/Результаты теста 1\|Результаты теста 1]]): «стал Директором» = мгновенная победа и конец партии (сработало 1/3, выглядело незаслуженным); редкие Жалобы — носители Ж оказываются руководителями и играть Жалобу им некуда; смена Директора по счётчику провалов декоративна; чередование ограничило Работников; «голосование за другое» никем не использовано; Аудитору тяжело следить — шпион ни разу не угадан.

**Подтверждено:** мотивация «Шпионажа» жива (3 Ш за 2 партии); «Антишпионаж» работает (2 прерывания краж за партию); проблема «Планктон лёгкой 8» не воспроизвелась; голосование понятно с первого раза (~1 за партию); раздача влияния осознанная, социальное ядро работает; длительность **20–30 минут**.

**Опровергнуто / не проверено:** «недоплата → месть» — 0 случаев за 3 партии; выгода аутсорса — аутсорса почти не было; Ш/Ж «не своим» целям — не использовались.
