# Проект 2

Карта «Проект», значение **2** — сложность и капитальная ценность.

**Выполнение:** сумма сыгранных карт «Работа» ≥ 2, иначе провал.
**Капитал:** выполненный → +2 прибыли, проваленный → −2 долга.
**Участников:** минимум 1 (⌈N/2⌉, считая руководителя) — руководитель с "двойкой" справляется сам.

См. [[Проекты/Карты Проект\|Карты Проект]], [[Правила/Правила#3. Выполнение проектов\|Правила#3. Выполнение проектов]] и [[Правила/Правила#2. Набор участников\|Правила#2. Набор участников]].
