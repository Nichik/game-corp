# Карты «Проект»

Колода проектов: **18 карт** — три «2», шесть «3», шесть «4», три «5» (единицы удалены 2026-11-09).

**Число на карте — сложность и капитальная ценность:**
- **выполненный** проект кладётся в капитал со знаком **+** (прибыль = сложности);
- **проваленный** — со знаком **−** (долг той же величины).

В чей капитал уходит проект, решает «Шпионаж»: при Ш ≥ 1 проект уходит Конкуренту, иначе — Корпорации. См. [[Правила/Правила#3. Выполнение проектов\|Правила#3. Выполнение проектов]].

## Личные символы целей

На картах проектов размещены **личные символы целей**: СК ([[Цели/Серый кардинал\|Серый кардинал]]), К ([[Цели/Карьерист\|Карьерист]]), П ([[Цели/Офисный планктон\|Офисный планктон]]). У [[Цели/Шпион\|Шпион]]а и [[Цели/Бухгалтер\|Бухгалтер]]а символов нет.

Распределение (2026-11-09):
- **«5» ×3** — на каждой СК + К + П (все три символа);
- **«4» ×6** — пары разных символов: СК+К ×2, СК+П ×2, К+П ×2;
- **«3» ×6** — двойной одинаковый символ: СК+СК ×2, К+К ×2, П+П ×2;
- **«2» ×3** — без символов.

Символы — основа начисления ПО: владелец цели получает ПО за каждый свой символ на выполненных проектах в капитале Корпорации (см. [[Правила/Правила#Победные Очки (ПО)\|Правила#Победные Очки (ПО)]]).

## Где проекты в игре

- **Каждый раунд** два проекта: один руководит Директор, другой — Менеджер; **ВЕТО** Директора (3 раза за игру, уходит в коробку) может оставить в раунде один проект.
- **Раздача (2026-11-09):** Менеджер берёт 3 верхние карты, передаёт Директору 2, одну сбрасывает закрыто; Директор назначает проекты себе и Менеджеру. См. [[Правила/Правила#1. Выбор проектов\|Правила#1. Выбор проектов]].
