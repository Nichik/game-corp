# Проект 3

Карта «Проект», значение **3** — сложность и капитальная ценность. Самый частый номинал в колоде.

**Выполнение:** сумма сыгранных карт «Работа» ≥ 3, иначе провал.
**Капитал:** выполненный → +3 прибыли, проваленный → −3 долга.
**Участников:** минимум 2 (⌈N/2⌉, считая руководителя).

См. [[Проекты/Карты Проект\|Карты Проект]], [[Правила/Правила#3. Выполнение проектов\|Правила#3. Выполнение проектов]] и [[Правила/Правила#2. Набор участников\|Правила#2. Набор участников]].
