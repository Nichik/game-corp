# Проект 5

Карта «Проект», значение **5** — сложность и капитальная ценность. Самый сложный и самый ценный номинал.

**Выполнение:** сумма сыгранных карт «Работа» ≥ 5, иначе провал.
**Капитал:** выполненный → +5 прибыли, проваленный → −5 долга.
**Участников:** минимум 3 (⌈N/2⌉, считая руководителя).

См. [[Проекты/Карты Проект\|Карты Проект]], [[Правила/Правила#3. Выполнение проектов\|Правила#3. Выполнение проектов]] и [[Правила/Правила#2. Набор участников\|Правила#2. Набор участников]].
