# Шпионаж (Ш)

Спецкарта «Работа», значение 1. В игре: 5.

**Эффект:** при **Ш > А** выполненный проект уходит к Конкуренту, проваленный — к Корпорации; при Ш ≤ А — наоборот. Сравнение — с [[Карты/Антишпионаж\|Антишпионаж]]ем, см. [[Правила/Правила#3. Выполнение проектов\|Правила#3. Выполнение проектов]]. Похищенные проекты считаются в целях [[Цели/Шпион\|Шпион]]а.

**Влиянием:** 1.

См. [[Карты/Карты Работа\|Карты Работа]].
