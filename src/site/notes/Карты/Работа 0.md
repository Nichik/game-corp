# Работа 0 («ноль»)

Обычная карта «Работа», свойств нет.

**Значение в проекте:** 0 — не помогает выполнить проект.

**Может стать Влиянием:** любая карта с руки — в том числе «ноль» — кладётся закрытой в зону влияния через аутсорс, а сыгранная в проект «ноль» может попасть во влияние по раздаче руководителя. Влиянием она добавляет 0 к сумме при подсчёте ≥8 и при голосованиях.

**Сколько в игре:** 17 при гипотезе состава общей колоды — 15 в общей колоде «Работа» (гипотеза), 1 у Серого кардинала, 1 у Бухгалтера.

См. также [[Карты/Карты Работа\|Карты Работа]] и [[Правила/Правила#Личные колоды\|Правила#Личные колоды]].
