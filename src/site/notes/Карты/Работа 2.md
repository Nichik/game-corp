# Работа 2 («двойка»)

Обычная карта «Работа», свойств нет. Самое большое значение обычной карты.

**Значение в проекте:** 2.

**Может стать Влиянием:** любая карта с руки — в том числе «двойка» — кладётся закрытой в зону влияния через аутсорс, а сыгранная в проект «двойка» может попасть во влияние по раздаче руководителя. Влиянием она добавляет 2 к сумме при подсчёте ≥8 и при голосованиях.

**Сколько в игре:** 9 — только в личных колодах (общая колода добора содержит только 0 и 1): Карьерист (2), Серый кардинал (1), Шпион (1), Офисный планктон (4), Аудитор (1). У Бухгалтера «двойки» нет — самая слабая стартовая рука по сумме.

См. также [[Карты/Карты Работа\|Карты Работа]] и [[Правила/Правила#Личные колоды\|Правила#Личные колоды]].
