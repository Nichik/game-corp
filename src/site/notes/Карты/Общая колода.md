# Общая колода («добор»)

Колода добора: 30 карт (гипотеза состава) — пятнадцать [[Карты/Работа 0\|«0»]] и пятнадцать [[Карты/Работа 1\|«1»]], без свойств.

**Зачем:** в конце каждого раунда все игроки добирают по 1 карте из общей колоды. Значений только 0 и 1 — сильные карты достаются только через личные колоды целей.

Состав по целям — в [[Карты/Карты Работа\|Карты Работа]], правила — [[Правила/Правила#4. Подведение итогов раунда\|Правила#4. Подведение итогов раунда]] и [[Правила/Правила#Личные колоды\|Правила#Личные колоды]].
