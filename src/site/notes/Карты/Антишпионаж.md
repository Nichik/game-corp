# Антишпионаж (А)

Спецкарта «Работа», значение 0. В игре: 4.

**Эффект:** при **Ш ≤ А** выполненный проект остаётся у Корпорации, проваленный уходит Конкуренту; при Ш > А — наоборот. Сравнение — с [[Карты/Шпионаж\|Шпионаж]]ем, см. [[Правила/Правила#3. Выполнение проектов\|Правила#3. Выполнение проектов]].

**Особенность Аудитора:** «Антишпионаж», спасший выполненный проект, добавляет его номинал к влиянию [[Цели/Аудитор\|Аудитор]]а.

**Влиянием:** 0.

См. [[Карты/Карты Работа\|Карты Работа]].
